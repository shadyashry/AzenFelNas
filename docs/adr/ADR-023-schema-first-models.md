# ADR-023 · Schema-first models with hand-written serializers, validated by fixtures

- **Status:** `[DECIDED]`
- **Source:** `DESIGN.md` §4 ADR-023 (binding index). This file is the long-form record; where they differ, `DESIGN.md` wins (ADR-000).

## Context

Stub generated in slice S01 from the `DESIGN.md` §4 index entry. Long-form context is added when this ADR is next amended.

## Decision

JSON Schema in `schemas/` is the contract. Dart: hand-written `freezed` + `json_serializable`; Kotlin: `kotlinx.serialization`; Swift: `Codable`; Go: generated by `go-jsonschema`. CI round-trips `schemas/fixtures/*.json` through every language and validates with `ajv`.

## Trade-offs

- **Win:** idiomatic code everywhere.
- **Lose:** four model sets kept in sync (fixtures catch drift).
